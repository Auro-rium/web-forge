      Does it actually get better?
      
  
      Each task family is run twice: cold (no skills, no memory, fresh start every task) and learned (skills and lessons carry over). Same tasks, same model.

      How the learning loop works
      
    
        
      
      1. Explore. On a new kind of task the worker drives the browser step by step with an LLM and the page's interactive elements.
        2. 
      
      2. Distil. Every action is recorded with a robust locator. A builder turns a successful trace into a parameterised skill, for example list_books(category), and checks it replays.
        3. 
      
      3. Remember. A reflector stores short lessons (site structure, pitfalls) in long-term memory.
        4. 
      
      4. Reuse. Next time the planner sees the skill catalog and the recalled lessons. A matching skill runs without any browsing LLM calls; failures fall back to exploring and repair the skill.
        5.

      Architecture
      
  
      A planner delegates browsing to a worker. Successful traces become skills; reflections become memory. Both feed the next run.
      
  
      
    
    
        
      
      1. Planner keeps a todo list and scratch files, recalls lessons, checks the skill catalog and decides what to delegate.
        2. 
      
      2. Worker sees a compact view of the page (interactive elements and text) and acts one step at a time.
        3. 
      
      3. Browser executes actions in headless Chromium. Navigation off the allowlist and risky actions (passwords, purchases) are blocked.
        4. 
      
      4. Skill builder converts a successful action trace into a parameterised, replayable skill and verifies it.
        5. 
      
      5. Skill library stores skills. The planner runs one with run_skill, replaying it with zero browsing LLM calls (dashed line).
        6. 
      
      6. Reflector distils what worked and what failed into short lessons.
        7. 
      
      7. Memory (Backboard, with a local mirror) recalls those lessons at the start of related tasks.
