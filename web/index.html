WebForge is an autonomous computer-use agent. It plans, sends parallel sub-agents into real browser tabs to search, read, click and fill forms, asks you before anything consequential, checks its own result, and hands back an answer plus files.


  


  

    No backend connected. The agent runs in a Python backend with Chromium on your machine
    (python -m webforge serve or docker compose up). Enter its URL under Connection.

    Architecture
    
  
    A planner breaks the job down and delegates. Sub-agents work in parallel, each in its own context and browser tab. Consequential actions wait for you; a verifier checks the result before it is returned.
    
  
    
    
    
      
      
    1. Planner keeps a todo list, a time and dollar budget, and a checkpoint after every round, so an interrupted run can resume.
      2. 
      
    2. Workers each get one subtask, a fresh LLM thread and their own browser tab; independent subtasks run in parallel.
      3. 
      
    3. Browser + safety gate: reading and navigation are allowed, submitting, sending, logging in and deleting ask you, payments are blocked. Passwords are typed from secrets the model never sees.
      4. 
      
    4. Search and analyst sub-agents: parallel web search with sources, and synthesis over workspace files in a separate context (comparisons, decisions, CSV).
      5. 
      
    5. Workspace: large results are saved to files instead of filling the planner's context; deliverables go to outputs/.
      6. 
      
    6. Verifier checks the final answer against every part of the task and sends the planner back if something is missing.
      7. 
      
    7. You answer questions and approvals from this page or the terminal; no answer in time means it proceeds safely or skips the action.
      8.
